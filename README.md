# LexproMax - Юридический сайт

Веб-сайт для юридической компании LexproMax, созданный на основе макета Figma.

## Структура проекта

```
lexpromax/
├── index.html          # Главная страница
├── css/
│   └── style.css      # Стили сайта
├── js/
│   └── script.js      # JavaScript функциональность
├── images/            # Изображения
└── README.md          # Документация
```

## Функционал

### Реализованные возможности:

1. **Адаптивный дизайн**
   - Десктопная версия (1200px+)
   - Планшетная версия (768px - 1024px)
   - Мобильная версия (до 768px)

2. **Интерактивные элементы**
   - Мобильное меню с анимацией
   - Переключатель языков (Укр/Eng/Рус)
   - Слайдер отзывов
   - Форма обратной связи
   - Плавная прокрутка к секциям

3. **Секции сайта**
   - Hero-секция с призывом к действию
   - Преимущества (3 карточки)
   - Онлайн юристы
   - Услуги (3 карточки)
   - Как мы работаем (с формой)
   - Отзывы клиентов (слайдер)
   - Почему выбирают нас
   - Footer с контактами

## Использование

1. Откройте файл `index.html` в браузере
2. Для разработки рекомендуется использовать Live Server

## Настройка изображений

Замените placeholder изображения в папке `images/` на реальные:

- `hero-bg.jpg` - фоновое изображение для hero-секции
- `service-1.jpg`, `service-2.jpg`, `service-3.jpg` - изображения услуг
- `avatar-1.jpg`, `avatar-2.jpg`, `avatar-3.jpg` - аватары для отзывов

## Доработки и расширения

Для добавления новых функций:

1. **Мультиязычность** - добавьте объект с переводами в `js/script.js`
2. **Backend интеграция** - подключите API в обработчике формы
3. **Анимации** - используйте библиотеку AOS или GSAP
4. **Больше страниц** - создайте дополнительные HTML файлы
